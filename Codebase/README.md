# Simple Python Tic-Tac-Toe

Hey! This is a simple, two-player command-line Tic-Tac-Toe game I built using Python. I wanted to keep the code clean, make it look nice in the terminal with some basic colors, and ensure it wouldn't break if someone types the wrong thing.

## What it does
* **Two players** take turns playing as X and O right in the terminal.
* **Colors!** Player X shows up in red and Player O in blue so it's easy to tell turns apart.
* **Guide numbers:** Empty spots show numbers 1 through 9 so you know what to type.
* **Crash-proof:** If someone types a letter instead of a number, or tries to pick a spot that's already taken, it just warns them and asks again instead of crashing.
* **Play again loop:** When a game ends (win or draw), it asks if you want another round.

## How to run it

1. Make sure you have Python installed.
2. Clone or download this repository.
3. Open your terminal/command prompt in the project folder and run:

```bash
python tic_tac_toe.py
